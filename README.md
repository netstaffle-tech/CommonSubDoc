# CommonSubDoc
CSD is a complete investor onboarding, Fund Management, and Compliance platform for modern fund managers and investors. Its complete Saas Product to handle multi-tenants.

## 🚀 Enhancements & Improvements

| 💡 **Feature** | 📄 **Description** |
|---------------|------------------|
| ⭐ **Investor Onboarding** | Digital, paperless onboarding with e-signature. |
| ⚡ **Investor Dashboard** | Portfolio, capital activity. compliance reports and statements. |
| 🔐 **Compliance & KYC** | AML/KYC, risk rating. accreditation and due diligence. |
| 💊 **Workflow Automation** | Automated workflows to accelerate processes and reduce manual work. |
| 🗄️ **Communications** | Integrated email, campaigns, and communication logs. |
| 🛠️ **Secure Data Room** | Centralized document repository with role-based access. |
| 📱 **Capital Calls & Distributions** | Automated capital calls, distributions, and real-time tracking. |
| 🎯 **CRM & Investor Management** | Manage investors, leads, notes, follow-ups and 360° profiles. |
| 🌐 **API & Integrations** | Seamless integration with CRMs, accounting, and third-party systems. |
